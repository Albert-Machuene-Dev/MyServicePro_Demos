# On The Rocks — Demo Website

A MyServicePro demo website for **On The Rocks**.

## Preview

```bash
cd restaurants/on-the-rocks
npm install
npm run dev
```

## Customize

1. Replace placeholder images in `src/assets/images/`.
2. Update menu, hours, and contact info in `src/data/restaurant.json`.
3. Build and deploy when ready.

## Build

```bash
npm run build
```
